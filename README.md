# Akan Name Generator

## Author

Ian Chelule

---

## Project Description

The Akan Name Generator is a web application that calculates the day of the week a user was born and assigns them a traditional Akan name based on their gender. Akan names originate from Ghanaian culture, where children are named according to the day they are born.

---

## Features

- Enter a birth date using a date picker.
- Select a gender.
- Calculates the day of the week from the birth date.
- Displays the correct Akan name.
- Validates user input.
- Responsive and user-friendly design.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript

## BDD (Behaviour Driven Development)

| Behaviour | Input | Output |
|-----------|-------|--------|
| User enters a valid birth date and gender | Date: 2008-03-07, Gender: Male | Akan name: Kofi |
| User enters a valid birth date and gender | Date: 2008-03-07, Gender: Female | Akan name: Afua |
| User submits without entering all fields | Empty form | Alert asking the user to fill in all fields |
